Install in four steps

  1. Download the APK with the button above. It is signed with a personal release key.
  2. Open the download. When Android asks, allow “install unknown apps” for your browser or Files app.
  3. Press the home button and choose Spartan Launcher > Always.
  4. Grant access in Settings → Focus & blocking (accessibility, display-over-apps, usage stats, notifications) to unlock blocking and screen-time.

Permissions, explained

  • Accessibility — detects the app you open so limits can be enforced and the notification shade can be opened by swiping down.
  • Display over other apps — the full-screen countdown that covers a blocked app.
  • Usage access — powers the screen-time report and daily limits.
  • Notification access — mutes the apps you choose; notification contents are never read or stored.

All of this runs on-device. Nothing is uploaded, shared or sold. See the privacy policy.
